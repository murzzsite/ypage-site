# YPage: лендинг для привлечения регистраций

Сайт: https://murzzsite.github.io/ypage-site/
Бренд: YPage (ypage.site), цвета #023E8A / #E85D04 из логотипа, шрифт Onest.
Заявки: Cloudflare Worker lead-relay, ref TZR29YZM32 (в script.js).

Живое: демо «описание → сайт» в hero и в блоке «Как работает», калькулятор стоимости.
Картинки в assets/ скачаны с ypage.site (иллюстрации клиента).
